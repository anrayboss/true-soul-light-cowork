## 六、網路行銷三大要素

📸 圖示：產品 ↔ 流量 ↔ 系統 三角架構圖

> 核心原則：**給予人們使用的價值，要多於他向你索取的金錢價格。**

### 6-1 產品

#### 產品三力
- **產品力**：產品本身的賣點（外觀、價格、CP 值）
- **品牌力**：客戶認知的賣點
- **行銷力**：透過「包裝」讓產品更好賣

#### 如何提升產品力
- **向內找**：差異化賣點（思考哪個賣點可以成為市場很強的；品質、形狀等）
- **向外找**：時事梗（疫情/紓困、報復經濟、寵物、節日、AI、時事人物）
- **水平找**：認同感

#### 什麼是品牌力？
- 當客戶期待你有新產品，開始有「品牌效應」
- 每次接觸被成交，累積效益：小成交 → 大成交
- 品牌金句：客戶覺得你有品牌力才有，客戶覺得你沒有就是沒有——**重點是先賣出產品**

#### 什麼是行銷力？
- 📸 截圖：電影「有錢」畫面——暗示行銷就是讓人感受到價值

#### 受眾設定
- 幾歲？住哪裡？痛點（需求點）是什麼？如何滿足？

### 6-2 流量

#### 流量來源
- IG、FB、YouTube、TikTok、店面、Threads

#### FB 流量演算法
- 動態排序三大關鍵：**時間近 → 分數高 → 連結高**

#### FB/IG PO 文超禁忌（會降觸及）
- 分享別人貼文
- 外部連結（LINE、YouTube、其他公司網站等）
- 誘使留言（「請在底下留言/分享」）
- 大量回覆私訊在短時間內
- 大量分享與 PO 文在短時間內
- 涉及 FB 違法內容
- 大量社團 PO 文被擋

#### 增加觸及率
- PO 文分數高 → 下一篇提升觸及
- 善用影片
- 圖文都很重要：**前三行要有重點**、拍片要三分之一、思考賣點與時事梗

#### FB/IG 主動創造免費流量方式（6 種）

| 種類 | 優勢 | 注意事項 |
|-----|-----|--------|
| 客戶推薦文 | 客戶說的話大家聽；把廣告費回饋給顧客 | 加入大社團；需要留言數 |
| 社團店家文 | 有些社團能無限推文 | 看板規；平時多互動 |
| 客戶推薦標註個人版文 | 客戶背書效果強 | 個人版人要多；讓利給客戶 |
| 個人版貼文 | 能自主掌握；當個人名片 | 多標註、多互動、多交朋友 |
| 粉絲頁留言增加觸及法 | 不用靠別人社團；官方帳號感 | 粉絲頁讚數很重要 |
| 限時動態 | 出現在首頁 | 好友數量要多；3 秒吸睛 |

## 七、行銷策略分析框架

📸 圖示：行銷策略流程圖（界定公司策略與規劃 → 分析內外部環境 → 決定行銷策略 → 決定行銷組合 → 策略分析與修正）

### 7-1 SWOT 分析

| | 有利因素 | 不利因素 |
|--|--------|--------|
| 內部環境 | **S 優勢** Strengths | **W 劣勢** Weaknesses |
| 外部環境 | **O 機會** Opportunities | **T 威脅** Threats |

- 📸 截圖：SWOT 填空練習題（課堂互動用）
- 📸 截圖：總體環境分析 SWOT 完整圖表（含優/劣/機/威四象限的詳細內容）

引用：神通集團董事長苗豐強——「任何企業，只要好好認識自己，並且看清楚周遭環境，左手把握自己的條件（SWOT），右手握住大環境變化（PEST），就可以掌握自己的命運。」

### 7-2 PEST 分析

| 因素 | 說明 |
|-----|-----|
| **P 政治**（Political）| 稅法、勞工法、政府政策、法令 |
| **E 經濟**（Economic）| 利率、匯率、經濟成長、消費水平 |
| **S 社會**（Social）| 教育水平、人口分布、風俗文化、生活趨勢 |
| **T 科技**（Technological）| 技術趨勢、政府科技投資、產業技術發展 |

### 7-3 STP 理論

| 字母 | 全名 | 說明 |
|-----|-----|-----|
| S | Segmenting 市場細分 | 將市場分成不同群體 |
| T | Targeting 目標市場選擇 | 選擇你要服務的群體 |
| P | Positioning 市場定位 | 在目標市場中建立獨特位置 |

> 「銷售的目標是為了滿足客戶的需求；行銷的目標是為了找出他的需要。」—— Philip Kotler

### 7-4 差異化策略

- 形象差異化
- 人員差異化
- 通路差異化
- 產品差異化
- 服務差異化
- 價格差異化
- 收費模式差異化

#### 差異化核心原則
- **「人無我有」**→ 市場創新第一
- **「人有我優」**→ 品質超越競爭者
- **「人優我廉」**→ 以價格取勝

### 7-5 4P 行銷組合

| 要素 | 說明 |
|-----|-----|
| **產品 Product** | 有形產品或無形服務；需了解產品週期、獨特賣點 |
| **價格 Price** | 定價影響銷售方式；與客戶感知價值相關，非客觀成本 |
| **促銷 Promotion** | 廣告、折扣、公關等所有行銷手法的統稱 |
| **地點 Place** | 銷售管道——店面、網路、大賣場；需與整體行銷策略相符 |

### 7-6 4C 顧客導向

| 要素 | 說明 |
|-----|-----|
| **Customer 顧客** | 先了解市場與顧客需求，提供客戶價值 |
| **Cost 成本** | 包含生產成本 + 顧客取得成本（時間、資訊蒐集） |
| **Convenience 便利性** | 重視顧客購買商品的方便性 |
| **Communication 溝通** | 建立雙向溝通，而非單向促銷 |

### 8-7 身心健康產業痛點與解方

痛點：
1. 無法數據化
2. 無法快速取得信任（溝通成本太高）
3. 無法複製（靠個人魅力）
4. 心靈太過無形
5. 顧客花了錢，卻常常「感覺不到差別」
6. 引流困難

### 8-8 儀器選擇標準
1. 高性價比，減少經營者壓力
2. 專業人士（如醫師）認同
3. 第一或唯一性，確保團隊安全
4. 效果快速（30 分鐘內）
5. 肉眼可見效果
6. 要有認證
7. 推出時間要長，不能讓消費者當白老鼠
8. 老公司、新市場
9. 有流量與名單來源
